# Matching and AI notes

The active matcher is deterministic and screens the complete bundled public
catalogue. It uses evidence-derived terms, project metadata, and stable scoring
so results can be inspected and reproduced in the browser workflow.

External AI reranking is labelled unavailable in the UI. Provider controls are
kept in Settings for future consented work; saving a key makes no provider
call, and the key remains only in the current browser session.
