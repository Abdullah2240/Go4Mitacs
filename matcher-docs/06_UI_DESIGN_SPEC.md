# UI specification

The product uses a warm off-white editorial surface, near-black ink, muted
metadata, deep cobalt actions, Newsreader display type, and a clean sans-serif
UI typeface. The shell contains Go4Mitacs, the project count, session notice,
settings, clear workspace, and sentence-case tabs for Evidence, Profile,
Matches, and Shortlist.

Evidence and Profile use a main workspace plus contextual aside. Matches uses
ranked research abstracts, filters, and a sticky project inspector. Shortlist
supports classification, reordering, Markdown export, and comparison of up to
four projects. Mobile layouts stack these regions without horizontal overflow.

Privacy copy: Your documents, profile, settings, and shortlist stay in this
browser. Clearing browser storage removes them from this device.
