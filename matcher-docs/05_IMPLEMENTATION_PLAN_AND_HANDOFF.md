# Implementation status and handoff

The active implementation includes browser-local evidence parsing, deterministic
profile generation, full-corpus matching across 3,359 public projects, filters,
project details, local shortlists, comparison, Markdown export, settings, and
same-origin Next.js routes.

The frontend direction is Editorial Research Desk: compact masthead, editorial
display typography, evidence/profile two-column screens, ranked match abstracts,
and a project inspector that becomes a drawer or stacked panel at smaller widths.
